# 📡 signal-generation — 信号生成（示例脱敏版）

## 定位
模型输出到排序信号的工程链路：特征聚合 → 打分 → 排序 → 风险过滤 → 输出中性化排序信号。

## 能力
- 仅输出排序信号，不宣称自动交易
- 内置风险过滤与合规声明：仅供参考，非投资建议

## 使用
作为量化管道一环被上层策略执行器消费，无自动下单能力。

## 安全边界（示例）
无自动交易、无凭据、无外部下单连接、无命令执行。分级 🟢 可入库。
