# 🔬 backtest-runner — 回测运行方法论（示例脱敏版）

## 定位
五阶段门控回测方法论：数据就绪 → 参数校准 → 样本内拟合 → 样本外验证 → 稳健性检查，进阶研究能力定位。

## 能力
- 阶段门控：每阶段通过才进入下一阶段，避免过拟合自欺
- 指标口径约定：收益/回撤/换手/胜率定义统一
- 合规声明：回测结果仅供参考，非投资建议

## 安全边界（示例）
