# 📈 strategy-protocol — 策略协议管理（示例脱敏版）

## 定位
量化选股策略参数化描述：可调参数、因子边界、组合约束、策略内核，**纯决策规则**，不含任何行情接口凭据。

## 能力
- 策略参数 schema 化：参数名、默认值、取值范围、边界
- 组合约束声明：权重区间、行业/风格暴露上限
- 合规声明：信号仅供参考，非投资建议

## 使用
作为协议定义被上层策略执行器消费，只读，无数据抓取。

## 安全边界（示例）
无行情抓取、无凭据、无网络写、无命令执行。分级 🟢 可入库。
